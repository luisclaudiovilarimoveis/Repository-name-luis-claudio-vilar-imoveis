## Como colocar o YouTube depois
No GitHub, abra `app-config.js`, clique no lápis e substitua somente:
`youtube: "xxxxxxx"`
por, por exemplo:
`youtube: "https://www.youtube.com/@NOME-DO-CANAL"`
Depois clique em **Commit changes**. Não altere `index.html` nem as coordenadas.
